Aplicativo pessoal de agendamento e publicação de conteúdo

O que é

liatestenoclose é um aplicativo pessoal, de uso individual, criado para agendar e publicar vídeos do perfil @testenoclose no TikTok, por meio da ferramenta de agendamento Postiz.

O aplicativo é operado pela própria titular da conta @testenoclose e não é destinado a terceiros. Ele existe apenas para automatizar a publicação dos vídeos de beleza produzidos para esse perfil.

Como funciona

  • Login Kit do TikTok — autentica a conta @testenoclose da própria titular.
  • Content Posting API — usada exclusivamente para enviar e agendar os vídeos da própria titular.
  • Postiz — ferramenta web de agendamento que executa as publicações programadas.

O aplicativo não coleta, acessa nem publica conteúdo de outros usuários.
